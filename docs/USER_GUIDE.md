# Guide utilisateur - rajiaa

## Demarrer

1. Ouvrir l'application dans le navigateur.
2. Importer un fichier audio compatible : MP3, WAV, M4A ou OGG.
3. Attendre l'affichage du lecteur et de la waveform.

## Creer une loop

1. Regler le debut et la fin avec les champs `Debut` et `Fin`, ou utiliser les handles sur la waveform.
2. Cliquer sur `Activer Loop` pour lire la selection en boucle.
3. Utiliser `Debut` pour revenir au debut de la selection.
4. Utiliser `Clear` pour reprendre toute la duree.
5. Utiliser `Lock` pour proteger la selection pendant la lecture.

## Exporter une loop

1. Nommer le fichier dans `Extraire le Loop`.
2. Choisir WAV pour un fichier non compresse, ou MP3 pour un fichier plus leger.
3. Cliquer sur `Extraire & Telecharger`.
4. Suivre la progression. Cliquer sur `Annuler` si necessaire.

## Sauvegarder dans la bibliotheque

- `Enregistrer` sauvegarde l'audio courant.
- `Enregistrer Loop` sauvegarde uniquement la selection.
- La bibliotheque permet de lire, telecharger, renommer et supprimer les audios.
- La recherche filtre par nom.
- Le tri permet d'organiser par date, nom, duree ou taille.

## Fusionner deux audios

1. Aller dans l'onglet `Fusion`.
2. Choisir deux audios differents depuis la bibliotheque.
3. Cliquer sur `Fusionner A + B`.
4. Ecouter le resultat, puis telecharger ou enregistrer.

## Bonnes pratiques

- Utiliser des fichiers courts ou moyens sur mobile.
- Preferer MP3 pour partager.
- Preferer WAV si la qualite prime sur la taille.
- Garder de l'espace libre dans le navigateur pour eviter les erreurs de stockage.
